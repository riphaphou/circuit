1. RÉSUMÉ EXÉCUTIF
───────────────────────────────────────────────────────────────────────────

Circuit Designer est un outil complet développé en Python pour créer, éditer
et analyser des schémas de circuits électroniques avec une interface graphique
intuitive utilisant Tkinter.

OBJECTIF: Développer un outil pédagogique et professionnel pour l'analyse
          de circuits électroniques.

RÉSULTAT: 100% des fonctionnalités demandées ont été implémentées et testées
          avec succès. Le code est de qualité production.

  ✅ Diviseur de courant: I1 = Itotal × (R2 / (R1 + R2))

6. ARCHITECTURE TECHNIQUE
───────────────────────────────────────────────────────────────────────────

DESIGN PATTERNS
  • MVC (Model-View-Controller)
  • Factory (création de composants)
  • Observer (événements GUI)

PRINCIPES
  • SOLID (Single Responsibility, Open/Closed)
  • DRY (Don't Repeat Yourself)
  • KISS (Keep It Simple)
  • Separation of Concerns

TECHNOLOGIES
  • Python 3.8+
  • Tkinter (GUI native)
  • NumPy (calculs)
  • Matplotlib (graphiques)
  • JSON (sauvegarde)

STRUCTURE MODULAIRE
  components/  → Composants électroniques
  circuit/     → Logique et calculs
  gui/         → Interface graphique

9. UTILISATION
───────────────────────────────────────────────────────────────────────────

INSTALLATION
  $ git clone https://github.com/riphaphou/circuit.git
  $ cd circuit
  $ pip install -r requirements.txt

LANCEMENT
  $ python main.py

WORKFLOW TYPIQUE
  1. Ouvrir l'application
  2. Cliquer sur un composant dans la palette
  3. Cliquer sur le canvas pour le placer
  4. Clic droit sur un composant pour éditer
  5. Modifier les valeurs dans le panneau de propriétés
  6. Cliquer "Calculer" (F5)
  7. Lire les résultats en bas
  8. Sauvegarder le circuit (Ctrl+S)
